# 告警级别“严重”选项设计

## 目标

补全告警规则的告警级别选项，使新增告警规则页和告警规则详情页均支持“严重”级别。

## 修改范围

- `13B-新增告警规则.html`：告警级别下拉框选项调整为“请选择、紧急、严重、一般”。
- `13A-告警规则详情.html`：只读告警级别下拉框选项调整为“紧急、严重、一般”。

## 约束

- 不修改现有规则数据及其默认告警级别。
- 不调整字段布局、样式、保存逻辑或其他表单内容。
- 新增页和详情页使用相同的有效级别集合与顺序。

## 验收

- 新增页下拉框可见“紧急、严重、一般”。
- 详情页只读下拉框包含“紧急、严重、一般”，可正确承载严重级别数据。
- 两个页面均无新增内容溢出或布局变化。
