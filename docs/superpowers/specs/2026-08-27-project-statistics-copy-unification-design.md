# 项目统计文案统一设计说明

## 目标

统一项目统计相关页面和公共脚本中的指定文案，同时保持质量趋势当前统计口径的视觉识别。

## 修改范围

### 质量趋势图例

- 图例固定显示“机器判定”“一次复判”“二次复判”。
- 去掉动态追加的“（当前）”与“参照”后缀。
- 当前统计口径对应图例仍使用蓝色标识，其他颜色及趋势线联动保持原状。

### 指定文案统一

- 完整词组“订单明细”统一为“项目明细”。
- 完整词组“订单统计”统一为“项目统计”。
- 完整词组“订单分析”统一为“项目统计”。
- 同步更新 HTML 展示、浏览器标题、菜单、面包屑、分页、权限配置、页面路由映射及依赖这些文案的 JavaScript 判断。

## 不在范围内

- 不修改“订单详情”“订单质量统计”“全部订单”等未指定文案。
- 不修改页面文件名、链接地址、URL 参数、对象数据字段或示例数据。
- 不调整页面布局、样式、字段顺序和业务功能。

## 实现约束

- 公共导航必须在所有页面保持一致，不能由运行时脚本恢复为旧文案。
- 删除或改造仅用于将“项目统计”恢复成旧文案的脚本逻辑。
- 保留现有导航目标 `01-项目统计首页.html`，只调整用户可见文案与对应文案映射。

## 验收标准

- `页面效果图` 下 HTML 与 JavaScript 中完整词组“订单明细”“订单统计”“订单分析”均无残留。
- “项目明细”“项目统计”在对应页面、菜单与权限配置中显示一致。
- 质量趋势图例不再出现“（当前）”和“参照”，切换统计口径时当前项仍保持蓝色高亮。
- 主 JavaScript 及全部 HTML 内联脚本语法检查通过。
- 本地 HTML 链接检查无缺失，且本次修改不产生内容溢出风险。
