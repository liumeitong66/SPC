# 订单详情页标题、返回入口与统计口径调整

## 目标

仅调整 `页面效果图/01A-项目明细.html` 的页面命名、返回入口位置和统计口径选项，不改变查询条件、指标卡、设备列表、PCB 明细及现有数据逻辑。

## 页面命名

- 浏览器标题由“项目明细”改为“订单详情”。
- 页面一级标题由“项目明细”改为“订单详情”。
- 面包屑统一显示为“订单分析 / 订单详情”。

## 返回入口

- 原“‹ 返回项目统计”改为“返回”。
- 从订单信息卡片中移除原返回入口。
- 将“返回”放入面包屑行最右侧。
- 数据更新时间保留，并与返回按钮组成面包屑右侧操作区；返回按钮始终位于最右侧。
- 返回目标仍为 `01-项目统计首页.html`。

## 统计口径

- 统计口径依次显示“机器判定”“一次复判”“二次复判”。
- 默认选中“一次复判”，保持当前默认状态。
- 三个选项复用现有分段控件样式和切换行为。
- 当前统计口径摘要继续随选中项更新。

## 适配与验收

- 常用窗口宽度及当前 1969×1272 窗口下不允许出现遮挡、截断或横向溢出。
- 面包屑左侧文字可正常收缩；右侧更新时间和返回按钮保持完整。
- 统计口径三个选项在筛选区内完整显示，查询按钮区域不受影响。
- 仅修改本页，不调整其他页面或公共组件。
