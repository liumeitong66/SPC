# 订单详情页结构与 PCB 明细链路调整

## 目标

调整订单详情页的命名、返回入口、全局统计口径、PCB 查询区和 PCB 明细列表，并新增独立的订单 PCB 详情页。

## 页面命名

- 浏览器标题由“项目明细”改为“订单详情”。
- 页面一级标题由“项目明细”改为“订单详情”。
- 面包屑统一显示为“订单分析 / 订单详情”。

## 返回入口

- 原“‹ 返回项目统计”改为“返回”。
- 从订单信息卡片中移除原返回入口。
- 将“返回”放入面包屑行最右侧。
- 数据更新时间保留，并与返回按钮组成面包屑右侧操作区；返回按钮始终位于最右侧。
- 返回目标仍为 `01-项目统计首页.html`。

## 统计口径

- 统计口径依次显示“机器判定”“一次复判”“二次复判”。
- 默认选中“一次复判”，保持当前默认状态。
- 三个选项复用现有分段控件样式和切换行为。
- 分段控件的选中状态随点击项更新。

## 页面精简

- 移除订单卡片中的覆盖设备、累计检测信息。
- 移除指标卡下方说明文字。
- 移除设备列表和 PCB 列表标题旁的辅助说明。

## PCB 查询区

- 查询区移动到 PCB 检测明细列表上方。
- 查询字段为时间范围、设备SN、检测结果。
- 检测结果使用统一多选下拉框，支持全部、良好、不良、直通、误报、漏报。
- 查询区末尾只保留重置、查询按钮。

## PCB 明细

- 字段固定为序号、板边条码、设备SN、设备所属区域、机器判定、一次复判结果、一次复判员、二次复判结果、二次复判员、操作。
- 操作列提供“详情”按钮。
- 详情按钮打开独立的 `01B-订单PCB详情.html`，页面内容与单板记录详情一致。
- 独立详情页从查询参数读取订单及 PCB 上下文，返回时直接回到原订单详情页。

## 适配与验收

- 常用窗口宽度及当前 1969×1272 窗口下不允许出现遮挡、截断或横向溢出。
- 面包屑左侧文字可正常收缩；右侧更新时间和返回按钮保持完整。
- 统计口径三个选项在页面顶部完整显示，PCB 查询按钮区域不受影响。
- 独立 PCB 详情页不得跳转或返回到单板查询模块。
