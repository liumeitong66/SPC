# 缺陷统计模板入口与固定列设计

## 目标

调整缺陷分析页的缺陷统计列表：模板名称作为查看缺陷分析详情页的直接入口，删除操作列，并在横向滚动时固定勾选框、序号和模板名称三列。

## 设计

- 模板名称使用原生链接，统一跳转至 `03A-缺陷分析详情.html`；详情页内容和数据不随模板变化。
- 删除表头和数据行中的操作列，不保留“查看明细”入口。
- 选择列固定宽度 44px，序号列固定宽度 60px，模板名称列固定宽度 180px。
- 三列通过 `position: sticky` 固定在左侧；模板名称列右侧增加轻微阴影，用于区分固定区域和横向滚动区域。
- 表头继续固定在顶部，表头层级高于固定数据单元格。
- 动态重绘、排序、统计口径切换和筛选后仍生成相同的链接及列结构。
- 不修改缺陷分析详情页，不增加查询参数和新字段。

## 验收

- 三个模板名称均可点击并进入现有缺陷分析详情页。
- 页面不再显示操作列。
- 横向滚动时勾选框、序号和模板名称保持可见，其他数据正常滚动。
- 勾选、排序、筛选、显示列及统计口径切换不受影响。
