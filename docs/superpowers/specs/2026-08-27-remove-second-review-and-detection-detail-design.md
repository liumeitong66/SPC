# 删除二次复判统计页与检测结果详情页设计

## 目标

删除“二次复判统计”和“检测结果详情”两个独立页面，清理其菜单、权限和跳转引用；同时保留现有业务链路中的二次复判数据，并以“单次 PCB 检测事件”为最小明细单元，重新确认删除后的字段全集。

## 删除范围

- 删除 `页面效果图/06-二次复判统计.html`。
- 删除 `页面效果图/02A-检测结果详情.html`。
- 从公共页面映射和角色菜单权限中移除“二次复判统计”。
- 删除公共脚本中仅服务于“检测结果详情”页的页面专属逻辑。
- 清理公共导航中针对“二次复判统计”的兼容处理，不保留失效页面入口。

## 跳转处理

- `页面效果图/03A-缺陷分析详情.html` 的三处“详情”链接改为跳转 `02B-单板记录详情.html`。
- 公共脚本中针对无明确链接的“详情 / 查看明细 / 查看 PCB”兜底跳转，由 `02A-检测结果详情.html` 改为 `02B-单板记录详情.html`。
- 不新增替代页面，不改变现有单板记录详情页结构。

## 数据保留边界

- 删除“二次复判统计”页面，只删除该独立统计入口及页面专属展示，不删除订单、PCB、器件等现有页面中的二次复判字段和统计口径。
- 删除“检测结果详情”页面后，该页面独有且没有其他现存页面依据的展示字段，不再计入当前系统字段全集。
- 业务统计仍以“每块 PCB 的最终判定”去重计算；明细数据的最小单元仍为“一次 PCB 检测事件”。同一 PCB 多次检测时，各次事件分别留痕，统计汇总时按板边条码取得最终有效判定。

## 删除后的单次 PCB 检测字段

以下字段只纳入删除后仍可在现存页面中找到展示依据的内容。

### 基本字段

- PCB 标识：板边条码、订单编号、拼板 ID。
- 设备信息：设备 SN、设备名称、设备所属区域。
- 检测时间：检测开始时间、检测时长（s）。

### PCB 级别字段

- 判定结果：机器判定。
- 一次复判：一次复判结果、一次复判时间、一次复判员。
- 二次复判：二次复判结果、二次复判时间、二次复判员。
- 器件汇总：器件总数、OK 总数、OK 率、机器判定 NG 器件总数、实际 NG 器件数、器件 NG 总数、特殊器件 NG 数、NG 率、误报数、误报率。
- 缺陷计数：现有页面中展示的 30 类缺陷数量字段。

### 器件级别字段

- 关联信息：板边条码、订单编号、设备 SN、拼板 ID、检测开始时间。
- 器件身份：位号、料号、封装类型。
- 缺陷信息：缺陷类型 / 不良类型。
- 判定信息：机器判定、一次复判结果、一次复判员、二次复判结果。
- 图片信息：RGB 图、白图。
- 当前现存器件级页面未完整展示一次复判时间、二次复判时间、二次复判员；因此这三项保留在 PCB 级全周期字段中，但不冒充为已有器件级展示字段。

### 统计数据字段

- PCB 统计：PCB 检测数、板卡总数、良好总数、DPPM、良率、机器判定 NG 板总数、不良总数、不良率、误报总数、误报率、直通总数、直通率。
- 器件统计：器件检测数、器件总数、OK 总数、OK 率、DPPM、误报 DPPM、NG 总数、NG 率、特殊器件 NG 数、直通总数、直通率、误报总数、特殊器件误报数、漏报总数、特殊器件漏报数、缺陷总数、现有 30 类缺陷数量。
- 统计范围：覆盖设备数、检测设备 SN、检测订单数、最后数据时间、参与统计设备、覆盖区域数。

## 随页面删除而移出的字段

- 仅在“检测结果详情”页出现、删除后没有其他现存页面依据的字段：算法代码、算法缺陷、器件类型、“封装”别名、器件图像、原图。
- 仅属于“二次复判统计”独立页的汇总展示：二次复判 PCB 总数、二次复判 OK 数、二次复判 NG 数、活跃工作站数、参与复判人员数、工作站工作量、人员工作量。
- 上述移出只表示不再属于删除后的“当前页面字段全集”，不推断或删除后端数据。

## 本次不处理内容

- 不在本次删除中顺带统一“检测时间 / 检测开始时间”“机器检测结果 / 机器判定”等字段文案；这些作为后续字段统一任务单独处理。
- 不新增字段、图表、筛选项、统计口径或页面。

## 验收标准

1. 两个目标 HTML 文件不存在。
2. 页面映射、角色权限和公共导航中不再出现“二次复判统计”页面入口。
3. 现存 HTML 和公共脚本中不存在指向 `06-二次复判统计.html` 或 `02A-检测结果详情.html` 的有效链接。
4. 缺陷分析详情页的“详情”可进入 `02B-单板记录详情.html`。
5. 订单、单板、缺陷和设备相关页面中的二次复判字段及统计口径保持不变。
6. 对全部现存 HTML 执行本地链接完整性检查，并检查常用窗口尺寸及当前用户窗口下的页面边界和内容溢出。
7. 不覆盖或回退工作区中与本次任务无关的既有修改。
