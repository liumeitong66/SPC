# 设备分析字段文案调整设计

## 目标

统一设备分析页面中模板数量和数据接收时间的字段名称，并同步“显示列”弹窗。

## 修改范围

- `检测订单数` 改为 `检测模板数`。
  - 设备明细列表表头同步修改。
  - “显示列”弹窗字段名称同步修改。
  - 设备分析顶部概览指标同步修改。
- `最后数据时间` 改为 `最后接收数据时间`。
  - 设备明细列表表头同步修改。
  - “显示列”弹窗字段名称同步修改。

## 实现方式

- 修改公共脚本 `deviceColumns` 中 `projectCount` 与 `lastDataTime` 的 `label`。
- 列表表头与“显示列”弹窗均由 `deviceColumns` 生成，因此复用同一字段名称来源。
- 修改设备分析概览中的 `检测订单数` 指标文案为 `检测模板数`。

## 不在范围内

- 不修改字段 key：`projectCount`、`lastDataTime` 保持原样。
- 不修改统计值、去重逻辑、列表数据、默认显示列和列顺序。
- 不修改项目详情、数据上传监控等其他页面中的“最后数据时间”。
- 不调整页面样式或布局。

## 验收标准

1. 设备分析顶部概览显示“检测模板数”。
2. 设备明细表头显示“检测模板数”“最后接收数据时间”。
3. “显示列”弹窗显示相同字段名称。
4. `projectCount`、`lastDataTime` 字段 key 和现有交互保持不变。
5. 公共脚本及全部页面内联脚本语法检查通过。
