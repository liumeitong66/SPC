# “订单编号”统一为“模板名称”设计说明

## 目标

将页面原型中完整词组“订单编号”统一展示为“模板名称”，并保持相关交互逻辑有效。

## 范围

- 仅处理 `页面效果图` 目录下 HTML 与 JavaScript 文件中完整出现的“订单编号”。
- 组合文案按词组替换，例如“输入订单编号”改为“输入模板名称”、“按订单编号去重”改为“按模板名称去重”、“全部订单编号”改为“全部模板名称”。
- 同步修改 JavaScript 中依赖该显示文案的比较条件、映射键、占位文案与提示文案。

## 不在范围内

- 不修改“订单分析”“订单统计”“订单缺陷汇总”“全部订单”“检测订单数”等其他包含“订单”的文案。
- 不修改页面文件名、链接地址、URL 参数、对象属性名和示例数据值。
- 不调整页面布局、样式、字段顺序或功能。

## 验收

- `页面效果图` 下 HTML 与 JavaScript 文件中“订单编号”残留为 0。
- 所有原“订单编号”位置均显示“模板名称”，组合文案语义同步更新。
- JavaScript 与页面内联脚本语法检查通过。
- 本地 HTML 链接完整性不因本次修改产生变化。
