# 可配置设备组织树设计

## 目标

将设备管理页从固定“所属区域”模式升级为客户级可配置组织层级，使不同客户可以分别使用“区域 → 产线”“区域”或“楼层 → 区域 → 产线”等结构，并通过左侧组织树联动右侧设备列表。

## 核心规则

- 每个客户使用一套统一的层级模板，同一客户内部不允许不同分支使用不同深度。
- 设备必须挂载在模板最末级节点，不允许挂载在中间层级。
- 点击任意上级节点时，列表展示该节点全部后代节点中的设备。
- 点击最末级节点时，列表展示直接挂载在该节点上的设备。
- 客户初始化时由平台管理员配置层级模板。
- 已有关联设备后，可以修改层级显示名称；新增、删除或调整层级顺序必须进入层级迁移流程。

## 当前客户演示模板

当前原型客户使用“区域 → 产线”模板：

- 区域A / 产线A1：AOI-01
- 区域B / 产线B1：AOI-02
- 区域C / 产线C1：AOI-03
- 区域D / 产线D1：AOI-04

树的类型根节点显示“区域”，其下展示实际区域节点和产线节点。

## 页面结构

### 目标视口

- 主要设计与验收尺寸：1440 × 900 px。
- 页面不得写死为固定画布，应在1440×900下完整容纳标题栏、查询区、组织树、设备列表和分页，并在更宽窗口继续自适应。
- 右侧表格允许在自己的容器内横向滚动，不能推动左侧树或越过页面边界。

### 布局

- 顶部标题栏保持现有结构。
- 查询筛选区保持全宽，保留“设备名称/SN”“设备状态”“重置”“查询”。
- 移除“所属区域”筛选，避免与组织树筛选发生冲突。
- 查询区下方改为左右两栏工作区：左侧设备组织树固定约240px，右侧设备列表占剩余宽度。
- 原设备列表标题、按钮、表格和分页整体进入右侧列表面板。

## 组织树展示与联动

- 左侧面板标题为“设备组织”，提供“层级设置”入口。
- 节点支持展开、收起；当前节点使用系统蓝色选中状态。
- 节点名称后显示其范围内的设备数量。
- 点击根节点“区域”显示全部4台设备。
- 点击区域节点显示该区域全部产线中的设备。
- 点击产线节点显示直接挂载设备。
- 右侧标题同步显示当前路径，例如“设备列表 · 区域A / 产线A1”。
- 列表总数和分页同步当前树节点及查询条件下的结果。
- 设备名称/SN、设备状态查询与树节点筛选取交集。
- 点击“重置”清空查询条件，并将组织树恢复到根节点。

## 节点管理

- 根节点“区域”只能新增区域，不能重命名或删除。
- 区域节点可以新增产线、重命名和删除。
- 产线节点可以重命名和删除，不能新增下级。
- 同级名称不能为空且不能重复。
- 有子节点或关联设备的节点不能删除，并展示明确原因。
- 新增、重命名、删除在当前原型会真实更新前端树结构、设备数量和选中状态，不增加后端持久化。
- 节点操作通过节点右侧操作按钮打开轻量菜单或复用现有弹窗。

## 层级设置

- 当前“区域管理”入口改为“层级设置”，并同时出现在组织树标题区。
- 弹窗展示当前模板“区域 → 产线”和每级名称。
- 支持修改层级显示名称并保存，树的类型根节点同步更新。
- 当前存在4台设备，因此新增层级、删除层级和调整顺序不能直接执行；点击结构调整入口展示“需要层级迁移”的说明和确认提示。
- 原型只展示迁移入口和约束，不实现后台批量迁移任务。

## 设备数据与归属

- 在设备行增加前端归属标识，保存区域和产线节点ID或稳定编码。
- 不向设备列表新增“所属产线”列，保留现有“所属区域”列。
- 新增、编辑设备弹窗中的“所属区域”“所属产线”继续保留，字段值应与当前组织模板一致。
- 本次不新增后端存储；刷新页面后恢复演示数据。

## 空状态与异常处理

- 当前节点没有设备时，右侧表格显示统一空状态，列结构保持不变。
- 查询条件无匹配结果时显示“暂无符合条件的设备”。
- 删除受限、名称为空或名称重复时使用现有 toast 反馈，不关闭编辑弹窗。
- 删除当前选中空节点后，自动选中其父节点并刷新列表。

## 不在范围内

- 不实现真实客户切换、后台数据库和跨客户层级模板存储。
- 不实现后台层级迁移任务。
- 不修改其他页面的设备筛选和统计结构。
- 不增加设备标签、自定义字段和拖拽排序。

## 验收标准

1. 1440×900下页面结构完整，无横向或纵向异常溢出、遮挡和重叠。
2. 左侧树和右侧列表在工作区内稳定布局，表格横向滚动不影响树。
3. 根节点、区域节点和产线节点点击后，列表、标题、总数和分页同步更新。
4. 查询条件与树筛选取交集，重置恢复根节点和全部4台设备。
5. 根节点、区域节点、产线节点的新增、重命名、删除权限符合约束。
6. 名称为空、同级重名和删除受限均有明确反馈。
7. 层级设置可修改层级显示名称；结构调整展示迁移约束。
8. 四台设备归属与确认的区域/产线映射一致。
9. 现有启停、编辑、删除、本机SPC、新增设备按钮保持可用。
10. 主脚本、页面内联脚本、本地链接和补丁格式检查通过。
