# 新增告警规则适用范围树联动设计

## 目标

完善新增告警规则页的适用范围树，让“全部设备—区域—设备”三级选择形成清晰、可见的数据联动，并在适用范围输入区域回显实际选中的设备名称。同时将推送消息模板的输入提示明确为 Markdown 文本。

## 方案选择

采用浏览器原生复选框的 `checked` 与 `indeterminate` 状态实现层级联动。相比自行绘制减号图标，该方案能直接获得可靠的半选视觉和键盘交互；相比仅显示已选数量，直接回显设备名称更符合用户明确要求。

## 适用范围树

- 设备复选框是选择状态的唯一数据源。
- 勾选“全部设备”时，所有区域下的全部设备同时选中。
- 取消“全部设备”时，所有设备同时取消选中。
- 勾选某个区域时，该区域下的所有设备同时选中；取消区域时，该区域下所有设备同时取消选中。
- 区域下全部设备选中时，区域为选中状态。
- 区域下部分设备选中时，区域为半选状态，复选框显示减号。
- 区域下没有设备选中时，区域为未选中状态。
- 全部设备选中时，“全部设备”为选中状态。
- 部分设备选中时，“全部设备”为半选状态，复选框显示减号。
- 没有设备选中时，“全部设备”为未选中状态。

## 适用范围回显

- 全部设备选中时显示“全部设备”。
- 部分设备选中时，按树中的顺序使用顿号连接并显示具体设备名称，例如“AOI-01、AOI-03、AOI-05”。
- 没有设备选中时显示“请选择设备”。
- 设备名称过长时在输入区域内单行省略，不允许突破容器边界；完整选择仍保留在树中可见。

## 推送消息模板

- 将文本域占位文案修改为“请输入 Markdown 类型文本”。
- 不新增额外说明行、标签或帮助图标。

## 实现边界

- 只修改 `页面效果图/13B-新增告警规则.html`。
- 不改变基础信息、推送接收群、监控周期、触发条件以及保存/取消按钮的现有结构和行为。
- 清理适用范围树现有重复事件绑定对新联动的影响，保证一次点击只产生一次状态变更。

## 验收标准

- 全选、区域全选、设备单选均能正确向上和向下联动。
- 半选状态在“全部设备”和区域级复选框中正确显示。
- 适用范围准确显示全部设备、具体设备名称或未选择提示。
- 推送消息模板占位文案为“请输入 Markdown 类型文本”。
- 1969×1272 与 1280×1118 下拉树不遮挡、不越界，页面无新增控制台错误。
