# 不良分析与误报分析导出弹窗设计

## 目标

为不良分析和误报分析页面的三个导出按钮增加统一的导出选项弹窗，在执行导出前展示导出范围说明、导出路径和是否包含器件图。

## 适用页面与入口

- `页面效果图/04A-不良导出.html`
- `页面效果图/04-误报分析.html`
- 每个页面的“导出该页报表”“导出所选类型”“导出所选位号”三个按钮共用一个弹窗。
- 原有按钮启用和禁用规则保持不变；禁用按钮不响应点击。

## 弹窗结构

- 标题：`报表导出选项`。
- 右上角关闭按钮：点击后关闭弹窗，不保存本次未确认修改。
- 说明：根据触发按钮显示当前导出范围，并统一提示单次最多导出 100 条，超过时仅导出前 100 条。
- “包括器件图”：复选框，默认勾选。
- “导出路径”：可编辑文本输入框，右侧提供文件夹选择按钮。
- 底部按钮：`取消`、`确认`，顺序固定。

## 导出范围说明

- 导出该页报表：说明导出当前页面筛选结果。
- 导出所选类型：说明导出当前树中选中的类型。
- 导出所选位号：说明导出当前树中选中的具体位号。
- 弹窗打开时根据按钮文本和当前选择动态生成说明，不新增页面外的导出类型。

## 路径选择行为

- 默认路径显示为 `C:\Users\shiyuan\Desktop\SPC导出数据`。
- 用户可以直接编辑路径文本。
- 文件夹按钮优先调用浏览器 `showDirectoryPicker()`。
- 浏览器允许选择目录时，输入框显示 `已选择目录：目录名称`。浏览器安全模型不提供完整本机路径，因此不伪造完整路径。
- 浏览器不支持目录选择时，保持当前路径不变，并在路径下方显示“当前浏览器不支持目录选择，请手动填写导出路径”。
- 用户取消系统目录选择时，不显示错误，也不修改当前路径。

## 确认与关闭

- 点击“取消”、右上角关闭按钮或遮罩空白处关闭弹窗。
- 按 `Escape` 关闭弹窗。
- 点击“确认”后关闭弹窗，并以页面轻提示显示已提交的导出范围；本原型不实际写入本地文件。
- 每次重新打开弹窗时保留当前页面会话内的路径和“包括器件图”选择。

## 一致性与边界

- 两个页面使用相同的类名、结构、尺寸、颜色、圆角、遮罩和交互。
- 弹窗宽度限制在视口内，窄屏下保留左右安全间距。
- 导出路径输入框与文件夹按钮不得挤压或越过弹窗边界。
- 不修改图表、树、查询条件、表格、分页和图片预览现有行为。

## 验收标准

- 两个页面共六个导出入口均能按启用状态正确打开同一规格弹窗。
- 三种入口的说明文案能区分导出范围。
- 复选框默认勾选且可切换。
- 路径可编辑，文件夹按钮具备支持与不支持两种处理。
- 取消、关闭、遮罩、Escape 和确认行为正确。
- 1969×1272、1280×1118 下弹窗无越界、遮挡和异常截断，页面无新增控制台错误。
