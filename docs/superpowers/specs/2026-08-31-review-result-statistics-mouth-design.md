# 复判结果统计口径配置设计

## 目标

按照用户提供的界面图片，将个人中心原“二次复判结果作为机器判定统计结果”开关替换为“复判结果的统计口径”配置。

## 配置项

- 名称：复判结果的统计口径
- 控件：沿用当前设置行的单选按钮样式
- 选项：一次复判、二次复判
- 默认值：一次复判
- 保存方式：继续纳入个人中心“保存更改”“取消”和本地持久化机制

## 数据结构

- 新字段：`reviewResultMouth`
- 可选值：`first`、`second`
- 页面控件名：`review-result-mouth`
- 读取旧设置时，将 `secondReviewAsOriginal: "off"` 迁移为 `first`，将 `secondReviewAsOriginal: "on"` 迁移为 `second`。
- 用户再次保存后仅保存新字段，不继续写入旧字段。

## 统计逻辑

- 移除旧配置“用二次复判覆盖机器判定统计结果”的行为。
- 机器判定、一次复判、二次复判三个明确统计口径继续分别使用各自数据，互不覆盖。
- 本次只建立新配置的展示、保存、取消、刷新回显和旧值迁移，不扩展其他统计页面结构。

## 页面范围

- 修改 `页面效果图/12-个人中心.html` 中的平台设置行和设置持久化逻辑。
- 修改 `页面效果图/spc-prototype.js`，删除旧配置对统计数据源的覆盖逻辑。
- 其他设置项、布局、样式和页面文案保持不变。

## 验收标准

1. 配置项显示“复判结果的统计口径”。
2. 右侧只显示“一次复判”“二次复判”，首次进入默认选中“一次复判”。
3. 保存后刷新仍回显已选值，取消可恢复上次保存值。
4. 旧 `off/on` 设置可分别迁移为“一次复判/二次复判”。
5. 机器判定统计不再被二次复判数据覆盖。
6. 页面内联脚本和公共脚本语法检查通过。
