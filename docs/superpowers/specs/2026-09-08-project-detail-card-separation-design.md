# 项目详情卡片拆分与复判字段简化设计

## 目标

移除项目详情页的统计口径控件，将检测设备分布和设备良率对比拆成两个独立卡片，并统一项目 PCB 列表与 PCB 详情页的复判字段名称。

## 页面结构

- 项目上下文卡仅保留模板名称，不再显示统计口径或切换按钮。
- 当前项目详情数据保持现有一次复判口径，不改变指标、图表和列表数据。
- 检测设备分布与设备良率对比在常用桌面宽度下并排显示为两张等高卡片。
- 两张卡片分别拥有独立标题栏、边框、圆角和内容区，不再共享同一个外层卡片。
- 1440×900 下保持单行双卡布局；窄于 1100px 时改为上下排列，避免内容溢出。

## 字段文案

- 一次复判结果 → 一判结果
- 一次复判员 → 一判人员
- 最终复判结果 → 终判结果
- 最终复判员 → 终判人员

以上四项同步应用于项目 PCB 列表和 PCB 详情页；复判时间字段保持原文案。

## 验收

- 项目详情页不再出现统计口径控件。
- 两个图表区域具备各自独立卡片边界和标题栏。
- 饼图悬停、良率条形图和纵向滚动继续有效。
- 项目 PCB 列表和 PCB 详情页的四个字段文案一致。
