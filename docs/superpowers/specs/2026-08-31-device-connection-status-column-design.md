# 设备连接状态列设计

## 目标

在设备管理列表中增加只读的“连接状态”列，便于直接查看设备当前是否连接。

## 列位置与展示

- 新列名称：连接状态
- 位置：设备状态之后、最后接收数据时间之前
- 展示形式：普通文本，不增加颜色标签、按钮或图标
- 可选文案：已连接、未连接

## 现有数据

- AOI-01：已连接
- AOI-02：已连接
- AOI-03：未连接
- AOI-04：已连接

## 交互范围

- 连接状态仅展示，不参与设备状态的启用/停用交互。
- 不增加连接状态筛选条件。
- 不根据最后接收数据时间自动计算连接状态。
- 不修改新增设备、编辑设备、删除设备和本机 SPC 操作。

## 验收标准

1. 表头“连接状态”位于“设备状态”和“最后接收数据时间”之间。
2. 四条设备记录均新增一个对应状态单元格。
3. 每行单元格数量与表头列数一致。
4. 页面布局、现有按钮和脚本交互保持正常。
