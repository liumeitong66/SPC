# 二次复判结果作为原始结果配置设计

## 目标

在“个人中心 → 基本设置 → 平台设置”新增统一配置项，使用户可以决定“机器判定”统计口径是否改用二次复判结果计算。

## 配置项

- 名称：二次复判结果作为原始结果
- 控件：复用现有“关闭 / 打开”单选按钮
- 默认值：关闭
- 保存方式：纳入个人中心现有基本设置的保存、取消和本地持久化机制

## 数据规则

- 关闭：保持当前逻辑，“机器判定”统计口径继续使用机器判定结果。
- 打开：“机器判定”统计口径改用二次复判结果。
- 打开后，缺少二次复判结果的数据视为无结果，不回退机器判定，也不参与该统计口径的有效统计。

## 页面范围

- 本次在 `页面效果图/12-个人中心.html` 增加配置入口及保存逻辑。
- 配置通过现有用户基本设置存储键持久化，供统计页面读取。
- 不改变统计口径按钮名称，仍显示“机器判定”。

## 验收标准

1. 基本设置中出现“二次复判结果作为原始结果”。
2. 首次进入时默认选中“关闭”。
3. 选择“打开”并保存后，刷新页面仍保持打开。
4. 点击取消可恢复至上次保存的值。
5. 配置值可被其他页面通过同一基本设置存储键读取。
