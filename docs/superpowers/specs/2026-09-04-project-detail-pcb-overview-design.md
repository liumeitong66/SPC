# 项目详情 PCB 总览设计

## 目标

项目详情以“当前项目检测了哪些 PCB”为核心，不再使用设备表联动 PCB 表。页面以 1440×900 为主要验口，同时保持更宽桌面尺寸下的边界完整。

## 页面结构

1. 保留页面标题、面包屑、项目名称和“机器判定 / 一次复判”统计口径。
2. 复用项目统计页的两组指标卡：
   - 板卡统计：PCB 检测数、板卡直通率、板卡 NG 率、板卡不良率。
   - 器件统计：器件检测数、器件直通率、器件 NG 率、器件不良率。
3. 指标卡下方放置“检测设备分布”饼图，展示各设备的 PCB 数量和占比。
4. 饼图下方依次为统一查询筛选区和项目检测 PCB 列表。

## 交互

- 饼图扇区支持鼠标悬停，提示设备名称、设备 SN、PCB 数量和占比。
- “检测设备分布”标题后不显示补充说明文字。
- 查询条件为时间范围、条码号、设备 SN、检测结果，末尾只保留“重置”“查询”。设备 SN 使用输入框，并提供最近 5 条查询记录供快速选择。
- 查询对 PCB 列表进行组合过滤；重置恢复默认时间和全部设备、全部检测结果。
- PCB 列表展示项目全部 PCB，并新增“设备 SN”列；每个 PCB 只占一行，同一 PCB 的多个条码号使用英文逗号连接，单元格溢出时通过鼠标悬停查看完整值；点击“详情”沿用现有 PCB 详情入口。

## 布局与边界

- 1440×900 下所有主要区域在主内容区内完整显示；指标卡、饼图和筛选区固定为紧凑高度，PCB 列表占用剩余高度并在内部滚动。
- 宽表仅在自身容器内横向滚动，表头保持吸顶，页面本身不得横向溢出。
- 小于常用桌面宽度时，指标卡保持四列压缩展示；不新增移动端专用交互。

## 数据

沿用页面现有项目、设备和 PCB 模拟数据，不改变业务数据含义；仅补足指标展示及设备分布所需的派生统计。

## 验收

- 页面中不存在设备对比列表与右侧下钻联动。
- 两组指标字段和项目统计页一致。
- 饼图悬停提示信息完整。
- 筛选区包含设备 SN，PCB 表格包含设备 SN。
- 查询、重置、统计口径切换和详情链接可正常使用。
- HTML 内联脚本可解析，差异检查无空白错误。
