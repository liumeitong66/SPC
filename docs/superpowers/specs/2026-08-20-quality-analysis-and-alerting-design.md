# SPC 二期质量分析与品质预警改版设计

## 目标

使缺陷分析、误报分析、不良分析和品质预警页面与 PRD 对齐，同时将所有页面的导航统一，移除设备上传监控入口。

## 全局导航

质量分析依次为：订单统计、设备分析、单板查询、缺陷分析、误报分析、不良分析、二次复判统计、品质预警。平台管理保留设备管理、用户管理、角色管理、个人中心。删除设备上传监控导航项和其脚本注入逻辑。所有页面使用同一导航顺序、链接、活动态和图标尺寸。

## 缺陷分析

- 查询字段仅保留时间范围与订单编号。
- 指标卡：缺陷总数、器件 NG 总数、器件直通率、板卡 NG 总数。
- 图表：器件 NG / 误报 / 直通占比饼图；虚焊、少锡、多胶、立碑、翻件、本体浮高、侧立、测距 NG 的降序柱状图，悬停显示数值。
- 订单统计表默认列为订单编号、板卡总数、机器判定 NG 板总数、板卡不良总数及不良率、板卡误报总数及误报率、器件 OK 总数、器件 NG 总数。其余 PRD 缺陷和器件字段可通过显示列选择。
- 表格支持多选导出，并通过详情进入可按时间范围、设备 SN、检测结果、一次复判员筛选的板卡缺陷详情。

## 误报分析与不良分析

- 两页共享不良类型、封装类型、料号、位号四维页签、查询条件、排名图表、树状下钻、器件明细、多选导出与显示列交互。
- 查询字段为时间范围、订单编号、设备 SN；未指定时展示全量数据。
- 不良类型使用饼图；其他维度使用按数量降序、仅前十名的柱图；树的根节点为当前维度，叶节点为不良类型或位号。
- 器件明细固定字段：序号、封装类型、不良类型、料号、位号、设备 SN、订单编号、RGB 白图、白图、板边条码、拼板 ID、检测开始时间、机器判定、一次复判。
- 误报分析统计口径为“机器判定 NG 且一次复判 OK”；不良分析统计口径为“机器判定不良”。原“不良导出”文案全部改为“不良分析”。

## 品质预警

- 总览指标：今日触发告警次数、今日推送告警信息条数。
- 图表：可切换设备/区域的告警次数柱图、按级别堆叠的告警趋势、告警规则分布饼图、前五高发规则柱图；悬停显示数值。
- 规则列表：规则名称、监控指标、适用范围、接收群名称、告警级别、状态、操作；预置 PRD 中七条规则。
- 状态规则：仅停用规则可编辑或删除；启用规则执行编辑/删除时提示先停用。
- 规则详情为独立页面：展示规则名称、监控指标、适用范围、触发条件、接收群名称、告警级别、规则状态和备注；历史触发记录可按设备名称、所属区域、时间范围筛选，记录含设备名称、所属区域、触发时间。

## 验收

- 导航中不再出现设备上传监控，且各页面导航一致。
- 相关页面字段、统计口径、图表类型、状态规则与 PRD 一致。
- 复用现有筛选器、表格、分页、提示、弹窗和配色；在常用宽度及当前窗口下无横向页面溢出、遮挡或截断。表格内容区可独立横向滚动。
