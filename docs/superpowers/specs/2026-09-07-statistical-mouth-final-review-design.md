# 统计口径与最终复判命名统一设计

## 目标

将平台所有统计口径统一为“机器判定、一次复判、最终复判”，并把用户可见的“二次复判”统一改为“最终复判”。

## 已确认方案

- 项目统计、项目详情、缺陷分析、设备分析的统计口径均按“机器判定、一次复判、最终复判”排列。
- 第三项继续使用内部值 `second`，仅改变用户可见文案和补齐切换入口。
- 点击任一统计口径后，相关统计卡片、图表和列表按已有数据模型同步刷新。
- 表格、详情、告警规则、筛选项和辅助提示中的“二次复判”统一显示为“最终复判”。
- 不修改 URL 参数名、数据对象字段名和现有数据传递方式。

## 一致性约束

- 四处统计口径使用现有 segmented 组件结构、尺寸、状态和交互样式。
- 选项顺序固定为机器判定、一次复判、最终复判。
- 不新增统计口径之外的字段、按钮或说明。
- 常用窗口宽度下三个选项不得溢出所属容器。

## 验收

- 全局搜索不到用户可见的“二次复判”。
- 四个统计口径组件均展示三项且可切换。
- 项目统计和设备分析复用共享 `second` 计算逻辑。
- 缺陷分析具备最终复判示例数据。
- 项目详情切换后统计指标和设备良率同步变化。
- 所有 HTML 内联脚本与共享 JavaScript 语法检查通过。
