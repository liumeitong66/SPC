# 项目统计口径与表格完整内容提示设计

## 目标

项目统计页仅提供“机器判定”和“一次复判”两种统计口径，同时让用户可以查看表格中因列宽被截断的数据全文。

## 统计口径

- 页面顶部“统计口径”仅保留“机器判定”和“一次复判”。
- 删除项目质量趋势中的“二次复判”图例、曲线和数据点，图表只展示机器判定与一次复判两条趋势。
- 此调整只作用于项目统计页，不删除公共脚本中供其他页面使用的二次复判数据与能力。
- 项目统计页任何交互均不得再把口径切换为 `second`。

## 表格完整内容提示

- 作用范围为项目统计页“项目明细”表格的表体单元格。
- 仅当单元格内容实际发生横向截断时，鼠标悬停或键盘聚焦显示完整文本。
- 未被截断的单元格不显示提示。
- 提示框复用平台深色信息浮层风格，自动在单元格上方或下方定位，并限制在视口范围内。
- 鼠标离开、失焦、页面滚动或窗口尺寸变化时关闭提示。
- 不改变表格列宽、行高、分页和横向滚动结构。

## 验收

- 项目统计页顶部不存在“二次复判”选项。
- 质量趋势图不存在“二次复判”图例、曲线、数据点及相关无障碍文案。
- 被截断单元格可通过悬停和键盘聚焦查看全文，提示框不越出页面。
- 1440×900 和当前浏览器尺寸下无新增页面溢出。
