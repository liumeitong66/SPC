# 项目详情设备对比与 PCB 下钻设计

## 目标

将项目详情页当前“上方设备表联动下方 PCB 表”的纵向主从结构，调整为“左侧设备质量对比、右侧所选设备 PCB 下钻”的同层工作区。核心任务是让用户先比较多台设备的质量表现，再定位异常设备对应的 PCB。

## 页面范围

仅调整 `页面效果图/01A-项目明细.html`。保留现有页面标题、项目摘要、统计口径、指标数据、筛选字段、PCB 数据、状态文案和详情入口；不修改其他页面或公共组件。

## 桌面布局

- 项目摘要和指标区保持现状。
- 原“项目检测设备”与“项目检测 PCB”区域合并为一个设备分析工作区。
- 工作区默认采用左右分栏：设备质量对比约占 65%，PCB 下钻面板约占 35%。
- 左侧以表格展示设备名称、设备 SN、板卡数、良率、DPPM、异常判断和“查看 PCB”入口。
- 右侧展示当前所选设备的设备 SN、良率、DPPM，以及该设备检测的 PCB 列表。
- 页面首次打开时默认选中质量表现最异常的设备；当前示例数据默认选中 `AOI-04`。
- 关闭右侧面板后，左侧设备对比表扩展为工作区通栏；再次选择设备时恢复分栏。

## 交互与数据流

1. 用户在左侧比较设备指标和异常状态。
2. 点击设备行、设备名称或“查看 PCB”入口后，将该设备设为当前选择并高亮对应行。
3. 右侧面板使用当前设备 SN 筛选 PCB 数据，并更新标题、设备摘要、列表条数和列表内容。
4. 用户可在右侧查看全部 PCB 或优先查看异常 PCB，并通过“查看详情”进入既有 PCB 详情页。
5. 原有时间范围、板边条码、设备 SN、检测结果筛选条件保留，并作用于右侧 PCB 列表；设备 SN 条件与左侧当前选择保持同步。
6. 点击重置后恢复默认筛选条件，并重新选中默认异常设备。

## 状态与边界

- 当前设备行同时使用浅蓝背景和选中状态，不只依赖文字颜色。
- 正常、关注、异常同时显示状态文字和圆点，不只依赖红绿颜色。
- 所选设备没有 PCB 时，右侧面板显示“当前设备暂无符合条件的 PCB”，左侧设备比较仍可操作。
- 筛选条件无效或时间范围倒置时，不更新结果，沿用现有筛选控件的校验表达。
- 右侧面板关闭时不清除筛选条件和当前选择，重新打开后恢复原状态。

## 响应式规则

- 在当前标注的 1766×1272 视口和常用 1920×1080 视口中必须保持真正左右分栏。
- 在内容区不足以容纳两栏时改为上下排列：设备对比在上，PCB 下钻在下。
- 两种布局均不得造成页面级横向溢出；宽表格的横向滚动限制在左侧设备表容器内部。
- PCB 下钻列表使用自身纵向滚动，不拉长整个页面工作区。

## 验收标准

- 页面不再出现上下两个完整表格的主从联动结构。
- 1766×1272 和 1920×1080 下，设备对比位于左侧，PCB 下钻位于右侧。
- 点击每台设备后，选中态、设备摘要和 PCB 列表同步切换。
- 关闭及重新打开右侧面板时，布局和状态符合设计。
- 时间、条码、设备 SN 和检测结果筛选，以及重置、查询、导出和详情跳转仍可使用。
- 在窄窗口中布局按规则堆叠，无重叠、遮挡或异常截断。
- HTML 内联脚本可解析，控制台无新增错误。
