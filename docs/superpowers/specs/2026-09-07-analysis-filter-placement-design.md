# 误报与不良分析查询区位置调整设计

## 目标

统一误报分析与不良分析页面左右工作区的查询条件层级，使查询条件归属于对应列表，而不是悬浮在列表卡片上方。

## 已确认布局

- 左侧工作区顺序：不良类型标题、位号查询输入框、类型树。
- 位号输入框不显示“位号”字段标签，保留搜索图标、占位文字、重置和查询按钮。
- 右侧工作区顺序：器件明细标题、器件明细查询条件、导出按钮、器件明细表格、分页。
- 左右查询区不显示独立外框和圆角；仅保留输入控件自身边框。
- 标题、查询区和导出区使用紧凑且一致的上下间距，导出区与表格之间保留浅色分隔线。
- 误报分析 `04-误报分析.html` 与不良分析 `04A-不良导出.html` 使用相同结构和样式。

## 交互边界

- 保留现有查询、重置、维度切换、树节点选择和导出交互。
- 筛选区按钮仍只能按“重置、查询”顺序显示。
- 导出按钮位于独立操作行，不进入筛选区。
- 不修改数据、字段、表格列和分页。

## 验收

- 两页左右筛选区均位于各自面板内部。
- 查询区外侧无嵌套边框，标题、控件、导出区之间的间距一致。
- 左侧搜索框上方不再出现“位号”标签。
- 右侧导出按钮位于查询条件下方、表格上方。
- 常用窗口宽度下不出现横向溢出或控件遮挡。
- 两页内联脚本语法和 HTML 差异格式检查通过。
