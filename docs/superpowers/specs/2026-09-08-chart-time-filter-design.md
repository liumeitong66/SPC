# 图表时间筛选组件统一设计

## 目标

将项目统计、设备分析和缺陷分析中的图表时间筛选统一为单行组件，支持手动日期范围与快捷周期下拉选择。

## 适用范围

- `01-项目统计首页.html`：良率对比。
- `09-设备质量分析.html`：良率对比。
- `03-缺陷分析.html`：缺陷类别分布。

## 组件结构

- 标题、开始日期、“至”、结束日期、快捷周期下拉框以及原有“查看全部”操作在桌面端同一行显示。
- 快捷周期下拉框提供“最近7天”“最近1个月”“最近半年”。
- 用户手动修改有效日期范围后，下拉框显示不可主动选择的“自定义”状态。
- 日期无效或开始日期晚于结束日期时，恢复上一次有效值，不刷新图表。

## 交互与数据

- 选择快捷周期后，同步更新开始与结束日期，并立即重绘对应图表。
- 手动修改日期范围后立即重绘对应图表。
- 项目统计与设备分析沿用现有良率对比数据及弹窗逻辑；设备/区域维度切换和“查看全部”保持不变。
- 缺陷分析沿用现有设备/区域切换及数据缩放逻辑，仅将三个快捷按钮替换为下拉框。

## 一致性与响应式

- 三页复用 `spc-common.css` 中的相同日期输入、分隔符和下拉框样式。
- 当前标注宽度和 1440×900 下保持标题栏单行，不允许控件重叠或越过卡片边界。
- 小于桌面常用宽度时允许缩小控件宽度；不得改变图表、筛选区或表格的既有布局逻辑。

## 验收

- 三处快捷周期均以单一下拉框呈现。
- 三个下拉选项及手动日期选择均可更新日期和图表。
- 项目统计和设备分析的良率对比标题栏保持单行。
- 缺陷分析的模式切换、日期范围和快捷周期保持同一工具行。
- 三页内联脚本语法通过，常用窗口尺寸无溢出、遮挡或重叠。
